# 抖音发布素材包（成片/图集 → 可上传）

## When to Use

- 已渲染好的竖屏成片(mp4)或图集(JPG 组)要发抖音, 需要封面候选、标题标签、发布话术和上传清单。
- 系列化发布(N 部成片按年份/主题逐期发)需要批量文案包。

成片(mp4)或图集(JPG 组)已就绪后, 产出可直接上传的发布素材: 主片 + 封面候选 + 标题标签话术。分工: 图文轮播的生产线在 douyin-tuwen; 发布后的数据复盘在 creator-analytics; 本技能只管「打包成可发布」。

## 打包流程（视频）

1. **主片就位**: 复制成片到素材包目录, 文件名带系列+年份（示例: `怀旧放映-1990年生-抖音竖屏.mp4`, 系列名换成你自己的）。验证: `ffmpeg -i` 读分辨率与时长——832x1216 竖屏 H.264+AAC 直传免转码。
2. **封面候选抽取**: 按内容节点抽 4 帧：`ffmpeg -ss <秒> -i 成片.mp4 -frames:v 1 -q:v 2 cover_X.jpg`。选点 = 片头章节卡(≈3s) + 各学段/段落中段。成片若自带字幕, 抽出的帧就是带文案的封面, 不用再排版。
3. **vision 定封面**: 逐候选判四样——第一眼吸引力、文字是否清晰、年代/主题感、有无现代元素穿帮。规则: 现代场景(宿舍自拍/手机特写)不能当怀旧封面; 章节卡上的年份文字会遮挡人脸, 章节卡作备选不首选; 保留首选 + 两张备选, 文件名写明用途（`封面首选-xxx.jpg`）。
4. **文案包**: 一个 `发布文案.md` 全含——标题 3 条（年份钩子「如果你是XXXX年生」/人群钩子/符号钩子）、标签组（大流量怀旧标签 + 年份标签）、封面选用说明、发布时间（21:00-23:00, 怀旧内容深夜共鸣最强）、评论区置顶话术（示例:「你是哪年生？评论区报年份，下期做你的年代」= 互动 + 系列铺垫一鱼两吃）。
5. **合规**: 发布页勾选「内容由AI生成」声明; 片尾品牌引流卡保留（符合平台规范）。
6. **交付形态**: 一个目录全含 主片 + 封面×3 + 发布文案.md, 相对路径, 用户拿到目录即可上传。上传路径: Mac 浏览器 creator.douyin.com 直传, 或 AirDrop 到手机发。

## 图集（图文）打包

图文页的生产（HTML 定版 + 渲染 + vision 验证）走 douyin-tuwen; 打包差异只有两条: JPG 按 p01…pNN 命名（1440x2400, sips formatOptions 88）, 发布时在抖音 App「图文」入口按序选图; 标题用「看到第几张你破防了」句式代替视频钩子。

## 文章体发布（长文案，非视频/图文）

作品要配深情长文发抖音「发布文章」时：文案三版本出齐（深情完整版首发 + 短钩子版备视频口播 + 长辈共创版收转发，发布节奏写在文案包末尾），标题 ≤30 字按「名字｜数字承诺」格式；年代细节从图库 caption 库里挖真实条目（每年代带选 2-3 条最扎心的，数据 100% 真实铁律同图文）；头图用三联横幅 1280x720（三个年代代表图各裁中条 hstack，ffmpeg crop+hstack 一步出）。Web 端自动化边界（只能填标题/摘要/正文，封面上传必须人工）与完整流程见 douyin-tuwen 技能「发布文章」节。站点地址若被正文吞掉，挪评论区置顶。

## 陷阱

- 工具目录可能只有 ffmpeg 没有 ffprobe: 时长从 `ffmpeg -i` 的 stderr `Duration: HH:MM:SS` 行正则解析。
- 系列化 = N 部成片 N 期内容: 文案包按年批量生成一次（每年一份标题/标签）, 发布时逐条取用, 不要每期现写。
- 抽帧选点不要只取片头: 单一章节卡封面千篇一律, 各学段中段的成片帧才是差异化封面; 定稿前必须 vision 过目, 画面精美但含现代物的帧必淘汰。
- 素材包必须与当前图库同代: 图库重做/扩库/质检修复后, 已打包的成片与封面引用旧图即作废, 整包重做——发布出去的成片若与其他年份撞图或含熔毁肢体, 会被观众以「产品很水」定性。打包前先核对成片 mtime 晚于图库最后一次变更时间。
- 发布链接与作品分离: 作品对外分发地址(网站)与素材包是两套东西。素材包不含线上地址时, 在发布文案末尾附你自己的永久站点地址作引流; 隧道类临时地址不发外部用户。
- AI 生成声明必勾: 发布页「内容由AI生成」不勾被平台检测到会限流, 打包时写进上传清单第一步而不是备注。
