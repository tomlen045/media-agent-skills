# 标题裁判 — 纯 Prompt 标题评分规则手册

不跑服务、不写代码也能用：任何 Agent 按本手册逐条核对标题，即可给出与本地评分引擎一致的可解释评分。**引擎版（零依赖 Python 本地服务，逐条自动计分）见 [github.com/tomlen045/title-referee](https://github.com/tomlen045/title-referee)**，规则库与本手册同源。

## 评分框架

**满分 100 分起步**，四步走：长度修正 → 标题党词表扣分 → 正向信号加分 → 结构信号加分。最后夹到 [0, 100]，映射等级：

| 等级 | 分数 | 判词 |
|---|---|---|
| S | ≥85 | 可直接发布：结构、合规、吸引力均衡 |
| A | ≥72 | 良好：微调 1-2 处可冲 S |
| B | ≥60 | 合格但平庸：按建议改写 |
| C | ≥45 | 有标题党/违规风险或明显短板，建议重写 |
| D | <45 | 高危：存在平台限流/处罚风险，必须重写 |

任一「高危」命中即标记 **标题党风险 ⚠️**。

## 第一步：长度修正（微信公众号上限 64 字）

| 情形 | 修正 |
|---|---|
| 空标题 | 直接报错 |
| >64 字 | **-20**（超出部分发布时被截断） |
| >30 字 | **-4**（手机订阅消息/分享卡片只显示前 ~30 字，关键信息可能被截断） |
| <8 字 | **-6**（信息量不足，读者无法判断内容价值） |
| 8-30 字 | **+3**（移动端最佳展示区间） |

## 第二步：标题党词表扣分（14 条，重复命中累计扣分）

**高危（命中即亮红灯）：**

| 句式 | 扣分 | 理由 |
|---|---|---|
| 震惊 / 惊呆 / 惊悚 / 吓死 / 炸裂 / 炸了 / 崩了 | -15 | 夸张情绪词，微信平台明令整治的标题党用语 |
| 不看后悔 / 后悔莫及 / 删前速看 / 速看马上删 | -15 | 制造恐慌+紧迫诱导，典型标题党句式 |
| 转发这 / 不转不是 / (繁体)轉發 | -15 | 道德绑架式转发诱导，平台明令禁止 |
| 99%的人不知道 | -12 | 虚构统计，平台重点整治句式 |
| 内部消息 / 内幕 / 泄密 / 机密 | -12 | 虚假内幕暗示，严肃违规风险 |

**中危：**

| 句式 | 扣分 | 理由 |
|---|---|---|
| 必看(句尾) / 不看必亏 / 千万别 | -10 | 强命令式诱导，降低平台推荐权重 |
| 刚刚 / 突发(句尾) / 紧急通知 | -10 | 假新闻句式，非真实突发禁用 |
| 你敢看吗 / 敢看吗 / 胆小勿入 | -10 | 好奇心胁迫句式 |
| 最全 / 最强 / 终极 / 史上最 | -8 | 绝对化用语，广告法与平台规范双重风险 |
| 第一(句尾) / 全网第一 / 第一人 / 之父 | -8 | 绝对化用语（广告法禁用词族） |
| 永久 / 100% / 百分百 / 绝对 | -8 | 绝对化承诺，不可验证 |

**低危：**

| 句式 | 扣分 | 理由 |
|---|---|---|
| 福利(句尾) / 白嫖 / 薅羊毛 / 免费领 | -6 | 利益诱导词，易被判定营销号 |
| 悬念省略号(句尾…) / 连环问号(？？？) | -6 | 滥用降低可信度 |
| 笑死 / 笑不活了 / 家人们谁懂 / kms | -4 | 网络流行语，时效性强易过气（视账号调性） |

**叠加惩罚：命中 ≥2 类高危时，每多一类再 -5**（标题党炸弹必须一票触底）。

## 第三步：正向信号加分（每类最多 +1 次）

| 信号 | 加分 | 理由 |
|---|---|---|
| 具体数字（N天 / N个 / N条 / N步 / N招 / N分钟 / N元） | +6 | 提升信息密度与可信度 |
| 干货信号词（保姆级 / 一文读懂 / 实战 / 实测 / 亲测 / 复盘 / 教程 / 指南） | +6 | 实用币（收藏转发动机） |
| 评测信号词（对比 / 评测 / 横评 / 选型 / 优缺点 / 踩坑） | +6 | 决策辅助类内容 |
| 疑问式（为什么 / 如何 / 怎么 / 什么是） | +4 | 触发好奇但不夸张 |
| 第一人称/亲历感（我 / 我们 / 亲历 / 我N年） | +3 | 真实币 |

## 第四步：结构信号加分

| 结构 | 加分 | 理由 |
|---|---|---|
| 【】栏目标签开头（标签 ≤8 字） | +3 | 识别度高 |
| 含分隔符（\| / ｜ / ：/ :） | +2 | 切分信息结构，扫读友好 |

**结构扣分**：标题 >15 字且以虚词/泛词开头（「…的」「关于 / 浅谈 / 论 / 记」）→ **-3**（前 10 字黄金位被浪费）。

## 改写方向建议（评完必给）

1. 命中高危词 → 删除/替换全部夸张词，用具体数字或亲历细节替代情绪渲染。
2. >30 字 → 把最关键的信息压进前 10 字（分享卡片只显示前半句）。
3. 全文无数字 → 加一个具体数字（天数/条数/金额），信息密度立涨。
4. 零正向信号 → 加干货词（实测/复盘/保姆级/对比）提升收藏动机。
5. 永远附上自检：**标题承诺的内容，正文兑现了吗？**（题文一致是平台红线）

## 示例评分

### 恶样本 → D 级

标题：**「震惊！99%的人不知道…」**

- 长度 12 字（8-30 区间）+3
- 「震惊」高危 -15；「99%的人不知道」高危 -12；句尾省略号低危 -6；两类高危叠加再 -5
- 无正向信号命中、无结构加分
- **得分 65 → B，但标记标题党风险 ⚠️（clickbait=true）**。高危词表命中即亮红灯，判分时风险标注与分数同样重要——再多一个高危词（引擎实测「震惊！99%的人不知道，不看后悔赶紧删」= 51.0 C）就滑向重写区。

> 引擎实测：`score_title("震惊！99%的人不知道…")` = 65 分 B 级（clickbait=true）。改写方向：删「震惊」「99%的人不知道」，换成具体数字+亲历细节。

### 干净样本 → S 级

标题：**「我用30天实测3款笔记软件：保姆级对比复盘」**

- 长度 21 字 +3
- 无任何标题党命中
- 正向信号全中：具体数字（30天/3款）+6、干货词（实测/保姆级/复盘）+6、评测词（对比）+6、第一人称（我）+3
- 结构：含分隔符「：」+2
- **得分 100 → S**，判词：可直接发布。

> 引擎实测：`score_title("我用30天实测3款笔记软件：保姆级对比复盘")` = 100.0 分 S 级。

### 更多引擎实测锚点

- 「震惊！99%的人不知道的秘密，看完删」→ 71.0 B（高危×2+叠加 -32，长度+3）
- 「不看后悔！史上最全攻略，转发这永久的福利？」→ 52.0 C（高危×2+中危×2+叠加 -51，长度+3）

## 判分纪律（Agent 必读）

- 一条一条核对词表，**不要凭语感整体打分**——引擎是逐条规则计分的，你也应该逐条。
- 重复命中同一句式按次数累计扣分（如「震惊」出现 2 次 = -30）。
- 正向信号每类只加一次，不按出现次数重复加分。
- 高危叠加惩罚独立于词表扣分，别忘了算。
- 每次输出都要：分数 + 等级 + 命中明细（含扣/加分理由）+ 改写建议，缺一不可。
- 本手册按微信公众号场景校准；其他平台（头条/小红书）字数截断线不同，长度维度需自行调整。
