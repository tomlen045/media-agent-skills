# 爆款样本拆解（公众号开源内容两大范式）

> 本文为脱敏版：账号专属案例已改写为通用示例，保留方法论与实测数值。

三个标杆样本的逐层实测拆解。混合路线的规则已提炼进 SKILL.md，本文保留样本细节供对标与二次参考。

## 样本一：教程型标杆（个人开源教程博主）

样本标题：《3 天暴涨 5700 Star，Browser Use 又让 Agent 更快了。》（搜标题可找到原文）

- **定位**：个人博主·教程闭环 · 午高峰发布 · 项目爆发几天内快跟
- **UI 实测**：正文 14px/行高2/字距0.02em/色 #3a3a3a；章节 h2 18px/600 + border-bottom 2px 墨绿 rgb(61,100,87)（品牌色只做章节签名线）；代码块 One Dark #282C34 底 + #ABB2BF 字 + Cascadia Mono；代码语言徽标=独立标签节 10px/600/大写/字距0.08em 灰字；全文仅 4 色（正文灰×73/代码灰×16/辅灰×8/品牌绿×6）；57 个短句段 + 7 内容图 + 1 SVG横幅 + 1 GIF + 2 视频号卡；无章节编号（内容非序列，编号是装饰就删）
- **结构**：行业冲突开头（以前卷能不能做→现在卷速度）→ 原理人话翻译（「把网页操作变成选择题」全文最值钱一句）→ 网友玩法（社区二创=社交证明）→ 缺陷披露章（Shadow DOM/iframe 不完善、DONE≠成功）→ 安装章完整命令+报错自救（--doctor）→ 文末裸链+关注+回复关键词
- **图片体系三层**（图片全量视觉验证结论）：①官方物料直搬（OG横幅/demo截图/结果面板/GIF）②社区解读背书（第三方信息图连免责声明都自带）③自有转化位仅文末——生产成本≈0 且可信度满分；快跟 3 小时的素材前提=根本不做图
- **文末 AI 聊天引流卡**：拟真微信聊天截图（读者问→AI 推 4 项目+星数+参考文章+「内容由AI生成」合规标注+反问钩子）——把关注升级成「获得一个 AI 工具」；每条消息都是 SEO 弹药；聊天 UI 自带社交证明
- **转发货币**：弹药（转给同事照装能用）
- **可抄**：缺陷披露章 / 报错自救命令 / 语言徽标 / 一句话原理放开头 / 4色纪律 / GIF+视频号双轨 / AI聊天卡
- **不学**：空洞封面大字（如 YYDS，信息量为零，全靠产品画面撑）

## 样本二：资讯型标杆（行业 AI 媒体）

样本标题：《暴涨47.3k Stars！字节开源Harness项目DeerFlow 2.0，让智能体几乎能完成任何复杂任务》

- **定位**：行业媒体·资讯科普 · 编辑署名 · 文首带自家研讨会硬广
- **UI 实测**：01/02/03 编号章节 + 22px 品牌蓝 rgb(37,119,231) + flex 双元素章节头；15px/17px 双字号混排（正文17、注释引文15）；5 张宽幅架构图（data-ratio 0.39~0.79）；0 视频；封面=GitHub 仓库页裸截图（实证流——截图星数滞后于标题反成「还在暴涨」活证据）
- **结构**：研讨会硬广 → 行业叙事（三年跃迁 Prompt→Context→Harness + 马具比喻 + Philipp Schmid 式权威定义）→ 01 项目介绍（功能清单）→ 02 使用方法（安装速览）→ 03 行业评论收尾
- **对照检查**：怎么装✅（4步）怎么用⚠️（功能罗列≠跑起来怎么玩）怎么避坑❌（零缺陷披露、零自救命令、key 去哪申请没讲）——概念科普+安装速览，非教程闭环
- **转发货币**：谈资（品牌势能+星数冲击+可复述比喻）；转发=行业人设武装
- **可抄**：概念叙事开头（跃迁框架+饭桌比喻）/ 权威引用一条提质感 / 编号章节+品牌色
- **不学**：文首硬广 / 代码粘贴换行丢失不处理 / 正文裸链不可点不挂阅读原文

## 样本三：社交货币全实弹药型（开源仓库揭秘类选题，双样本拆解后的实战整合）

选题：某汇集多家 AI 公司系统提示词的开源仓库（数万星，GitHub API 实时核定）。

- **选题验证**：社交货币浓度=能否当谈资在群里转述 + 围观人数/星数冲击；不装任何东西的项目零门槛，受众最宽
- **瓜点结构的弹药必须原文实拍**：抓仓库真实文件（jsdelivr CDN 拉 raw md）做成黑底绿字证据卡（英文原文+▲翻译图注），一张卡=一个不可反驳的瓜；项目无官方宣传物料（assets 只有赞助商 logo）时，第二来源=用真实文件内容自行排版证据卡——内容 100% 真实，排版是唯一的创作
- **数据口径三处修正**（发布前自检实测抓出）：API pushed_at 是 UTC（直接换算写出「凌晨」假话→改「发稿前几分钟还在更新」）；目录计数含子目录（「29 个文件」改「29 份档案」）；Trending 页星数快照滞后实时 API 数百上千
- **争议性选题的两道护栏**：「一句大实话」黄卡界定边界（社区逆向汇编≠官方部署版本）；硬规则自查——描述安全研究事实可以，提供攻击指导不可以；文末互动作业（去问你的 AI）= 读者自产内容替代视频位
- **多轮加料路径**：v1 纯文字 → v2 加原文证据卡/五步操作卡/防越狱实据 → v3 加国产同类产品对比（「体量光谱」角度，中文读者最有着落感的原创角度）——每轮加料都是先抓新真实素材再动笔，不是空扩写

## 三样本汇合点

- 共同点：转发都是社交货币（一个发弹药、一个发谈资）
- 共同缺陷：标杆账号都没做阅读原文转化闭环——这是自有账号最大的差异化突破口
- 混合路线的落地规则见 SKILL.md「热点文混合路线」与「转发文变体」
